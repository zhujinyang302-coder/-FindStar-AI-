# Demo 演示脚本（寻物星图 FindStar）

## 0. 准备

```bash
# 后端
cd backend && pip install -r requirements.txt
python ../scripts/init_db.py
python ../scripts/seed_demo_data.py
uvicorn app.main:app --reload --port 8000

# 前端（另开终端）
cd frontend && npm install && npm run dev
```

访问 http://localhost:5173 ，使用演示账号登录。

可选：设置 `AI_PROVIDER=openai_compatible` 并配置 `AI_API_BASE/AI_API_KEY/AI_MODEL_NAME`
以演示真实模型；未配置时页面会明确显示“降级状态”。

## 1. 首页与浏览

1. 打开首页：展示产品名、两个主入口、最新公开记录与基础统计；
2. 在搜索框输入“耳机”回车 → 跳转列表页并带入关键词；
3. 列表页切换类别/类型筛选，刷新页面验证筛选条件可恢复；无结果时点击“清空筛选”。

## 2. 发布记录

1. 登录普通用户（`alice@findstar.demo` / `User@2026`）；
2. 点击“我丢了东西”，上传 1 张图片（或跳过，观察“无图降低匹配效果”提示）；
3. 填写标题“黑色无线耳机”、描述、类别“电子产品”、颜色“黑色”、地点“教学楼二楼”；
4. 点击“AI 识别特征”，观察结果（真实模型或降级标注），可修改后提交；
5. 提交成功跳转详情页，提示可发起智能匹配。

## 3. 智能匹配

1. 在详情页点击“开始智能匹配”；
2. 结果页展示 Top 3 候选、分项分数、匹配理由与待核验点；
3. 说明：分数为算法分数，不代表找回概率；视觉项不可用时标注为“不可用”；
4. 对照负样本（蓝色长柄雨伞）验证其未进入高排名。

## 4. 认领与审核

1. 在候选结果页点击“提交认领申请”，填写私密核验信息（如“耳机盒内侧有划痕”）；
2. 在“我的申请”查看状态为“待审核”；
3. 切换管理员账号（`admin@findstar.demo` / `DemoAdmin@2026`）进入管理端；
4. 打开待审核申请详情，查看私密核验信息与分项依据；
5. 点击“通过”，在二次确认弹窗确认 → 目标记录状态更新为“待确认”，并写入审计日志；
6. 返回“我的申请”，状态变为“已通过”。

## 5. 安全与降级演示

1. 未登录访问 `/admin` → 跳转登录；以普通用户访问 `/admin` → 被拒绝；
2. 上传可执行文件或伪装扩展名文件 → 返回 415；上传 > 5 MB 图片 → 返回 413；
3. 请求超过限流阈值的 AI 识别接口 → 返回 429；
4. 断开 Redis（或未配置）→ 列表查询仍正常，日志显示降级为内存缓存。
